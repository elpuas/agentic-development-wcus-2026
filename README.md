# Agentic Development for WordPress

## Building with AI Workers, Not Just AI Chat

Resources from my session at [WordCamp US 2026](https://us.wordcamp.org/2026/announcing-our-first-round-of-speakers-2/) in Phoenix, Arizona.

This session explores how development teams can move beyond isolated prompts and build repeatable AI-assisted workflows around three foundational layers:

1. **Project instructions** provide agents with repository-specific context, conventions, and constraints.
2. **Reusable skills** capture procedures, checklists, and specialized workflows.
3. **External tools** allow agents to inspect systems, validate results, and take action.

## Resources

### WordPress and Agentic Development

- [Agents and Skills in the Gutenberg Project](https://developer.wordpress.org/block-editor/contributors/code/agents-and-skills/) - How WordPress organizes `AGENTS.md`, directory instructions, reusable skills, references, and progressive discovery.
- [WordPress Agent Skills](https://github.com/WordPress/agent-skills) - Portable WordPress knowledge and workflows for AI coding assistants.
- [Gutenberg AGENTS.md](https://github.com/WordPress/gutenberg/blob/trunk/AGENTS.md) - A real-world example of repository-level instructions in a large open-source project.
- [Gutenberg Skills](https://github.com/WordPress/gutenberg/tree/trunk/skills) - Task-specific skills used by contributors working on Gutenberg.

### Open Agent Standards

- [AGENTS.md](https://agents.md/) - A simple, open format for guiding coding agents.
- [Agent Skills](https://agentskills.io/) - An open format for packaging reusable instructions, procedures, references, and scripts.
- [Agent Skills Specification](https://agentskills.io/specification) - The technical specification for `SKILL.md`.
- [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) - An open standard for connecting AI applications with external tools and systems.
- [MCP Architecture](https://modelcontextprotocol.io/docs/learn/architecture) - An overview of MCP clients, servers, tools, resources, and prompts.

### Research

- [On the Impact of AGENTS.md Files on the Efficiency of AI Coding Agents](https://arxiv.org/abs/2601.20404) - An empirical study involving 10 repositories and 124 development tasks.
